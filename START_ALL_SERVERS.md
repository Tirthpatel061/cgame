## Run all servers

```
python "start_all_servers.py"
```

### Starts
- Auth + OTP server (`Login Module/auth_server.py`) on port 5002
- Arena/game server (`ITM/backend3ds.py`) on port 5000
- Mentor app (`Mentorr/mentor.py`) with the GUI window

### Notes
- Use the same Python environment where you installed `Login Module/requirements.txt`.
- Press `Ctrl+C` to stop all servers.
